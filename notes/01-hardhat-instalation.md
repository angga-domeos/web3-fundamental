# Instalasi Hardhat 3

Hardhat adalah lingkungan pengembangan smartc ontract (environtment development) dan framework sumber terbuka yang digunakan developer profesional untuk mengembangkan, mengkompilasi, testing dan deploy smart contract

Requiment Instalasi:
- node js : min v22.13.0

Cara Instalasi : 
- npx hardhat --init

Template yang digunakan pada instalasi ini:
```
npm install --save-dev "hardhat@^3.9.0" "@nomicfoundation/hardhat-toolbox-mocha-ethers@^3.0.7" "@nomicfoundation/hardhat-ethers@^4.0.13" "@nomicfoundation/hardhat-ignition@^3.1.7" "@types/chai@^5.2.3" "@types/chai-as-promised@^8.0.1" "@types/mocha@>=10.0.10" "@types/node@^22.8.5" "chai@^6.2.2" "ethers@^6.14.0" "forge-std@foundry-rs/forge-std#v1.9.4" "mocha@^11.0.0" "typescript@~6.0.3"
```
